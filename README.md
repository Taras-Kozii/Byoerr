Byoerr — a modern responsive landing page for a restaurant, lounge space, or premium hospitality brand. The landing page is designed with a focus on visual content presentation, typographic hierarchy, and immersive user experience. The page structure is built to focus the user’s attention on the brand, services, and call-to-action elements.

## 🔗 Live Demo

[Byoerr](https://taras-kozii.github.io/Byoerr/)

## 🚀 Core Technologies

- HTML5 — semantic page structure
- CSS3 — styling, responsive layout, and UI animations
- JavaScript (Vanilla JS) — interactivity and interface behavior
- Responsive Web Design (RWD) — adaptation for mobile/tablet/desktop
- Flexbox & CSS Grid — building a modern layout system
- CSS Transitions & Animations — smooth hover effects and transitions
- Git & GitHub Pages — version control and project deployment
